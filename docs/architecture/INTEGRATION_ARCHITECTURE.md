# Integration Architecture

Module 25 owns adapters, credentials, delivery status, retries and monitoring; domain modules own business transactions. Prefer outbox plus queue, correlation IDs, idempotent handling, bounded backoff, dead-letter review, reconciliation and redacted logs. Banking/payment adapter reports outcomes to treasury (14); e-GP adapter exchanges approved procurement records with (09); payroll imports are owned by (19), source payroll remains authoritative; revenue channels report to (15); government reporting exports require dataset approval. Use mocks until specifications, credentials and authorization exist. Each go-live contract needs owner, version, schema, classification, authentication, replay protection, timeout/retry, ordering, error mapping, reconciliation, retention, monitoring and test environment. No official integration is claimed.
