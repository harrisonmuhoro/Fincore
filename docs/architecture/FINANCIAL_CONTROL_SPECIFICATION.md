# Financial Control Specification

Persist money as MySQL DECIMAL, calculate with decimal-safe arithmetic, define precision/rounding and currency. Never use floats. Budget checks lock relevant balances or use an equivalent concurrency-safe ledger; calculate approved availability, reject overspend and record the decision atomically. Commitments and callbacks are idempotent. Journals must balance before posting, validate account combinations and open periods, retain immutable source references and actor history. Posted entries cannot be edited/deleted; corrections are authorized linked reversals/adjustments. Closed periods block posting/backdating; reopening requires privileged approval and audit. Separate voucher approval from treasury execution. Prevent duplicates by durable business/idempotency keys; reconcile uncertain outcomes before retry. Test concurrency, balancing, rounding, duplicates, reversals and period locks.
