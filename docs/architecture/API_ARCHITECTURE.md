# API Architecture

Proposed prefix `/api/v1/`, JSON REST, Sanctum user auth and separately scoped service auth. Controllers authenticate, authorize and validate then call application actions; domain services enforce invariants. Policies/Gates check object and organization scope on every request. Use pagination, allowlisted filters, stable IDs, UTC timestamps, decimal-safe KES serialization, masked sensitive fields and consistent validation/conflict errors. Collection GET/POST; resource GET/PATCH; explicit POST commands for submit/approve/return/post/reverse/close/reconcile. No arbitrary status mutation. Idempotency keys and durable references for sensitive financial commands. Publish OpenAPI and contract tests. Webhooks require signature/replay protection, bounded retries and reconciliation.
