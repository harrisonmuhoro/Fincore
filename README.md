# FinCore County

Proposed enterprise county PFM platform; documentation planning only. Stack: Laravel/PHP 8.3+, Sanctum REST, React/TypeScript/Vite/Tailwind/shadcn, MySQL 8, Redis and private document storage. Modular monolith; KES; fictional data; no claim of official affiliation/integration.
